# 猴子森林安全台远程策略

适用场景 request_id：`5ac70696f3954ad389bb41a83a6d2ed3`，1366×768 原生画面。
将本目录的两个 JSON 与该场景原有 seed、scene、world_geometry 一起使用。
文件与其它场景不通用；运行时检查 request_id，并匹配小地图静态地形。

- 人物坐标仅来自小地图唯一黄点。名字、外观不再参与运行时定位。
- `minimap_calibration.json` 将小地图坐标映射到已复核的地图坐标。
  比例为 1/16，实际定位分辨率约 16 像素，行走时持续按方向键，仅在接近落脚点或绳子时刹停确认。
- `safe_platforms` 限制射击位置与中途落脚点；`firing_platforms` 扩展到已确认的上半部安全台。
  当前看到怪占据的安全台也会被拒绝。不会因某段怪物平台暂时空着就走过去。
- 黄点分辨率不足以精确接近狭窄重叠边缘时，从原台内部向目标台起跳，避免走到边缘后惯性滑落。
- 无目标时先在安全台等待刷新，再沿安全台路线换位。优先使用可见的中途落脚点。底部叶台、地面及下层平台不在活动白名单内。
- 看不清黄点或地形时松键等待；缺少校准时 GUI 禁止开始挂机。

|---|---|---|
| left_top | 左 | left_upper |

用户随后授权将这四个例子拓展为自适应站位。`reviewed_firing_examples` 保留原始标注供复核，运行时允许从其它已确认安全台向任一侧攻击射程内的猴子。`combat_platforms` 限定真实怪物平台，防止把安全台上的猴子宠物当成远程目标；它不会放开人物落脚平台的限制。固定方向模式仍可通过 `firing_lanes` 配置启用。

本轮效率目标：2026-09-27 最新人工示范 20400 EXP / 599.412 秒 = 2042.001 EXP/分钟的 80%，
即 1633.601 EXP/分钟。必须以独立实机录像和 HUD 读数检验，离线回放不能证明达标。
