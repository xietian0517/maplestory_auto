# 自定义守台：三步标定

统一助手 v2.2.1 的 `platform_guard` 模式支持三步标定。随包提供猴子沼泽3示例；自己的角色和地图应重新标定。

先把人物站到希望守台的位置，选择“截图标定”，三秒内切回游戏；也可以复制完整游戏画面，点“粘贴画面标定”。

1. **固定参照物**：框选附近固定不动、清晰的平台纹理。
2. **人物名字**：紧贴完整名字框一行。截图时的名字中心自动成为回位位置。
3. **观察区域与怪物**：先框怪物观察区域，松开后直接继续框选怪物身体、头部或光圈。可连续添加多个框，完成后保存。

框完自动进入下一步；重画某一步可点顶部对应按钮。第三步的“添加怪物框”可随时继续补框，不再要求框选平台边界或停靠范围。选择 right（右）、left（左）、both（两侧）、攻击键与水平射程后，点“测试守台识别”查看标记。

## 站位与识别

新方案以截图时的位置为目标，左右 20 像素内不微调；偏离超过 90 像素时停键等待。这个范围用于限制回位，不代表识别出了平台边缘。截图前请选择两侧有移动余地的站位；怪物观察区域只用于找怪，不会被当作可行走的平台。人物高度不拦截动作。

有射程内目标时优先攻击，空场后回位；临近回位限制时先处理位置。两侧模式先保持当前攻击方向，该侧连续 0.3 秒无目标且另一侧有目标后才换边。转向必须看到对应方向的实际位移后才允许攻击。人物或参照物未找到、偏离过远、识别超过 120ms 时松键等待。

方案保存到程序旁 `user_templates/guards/<编号>/profile.json`，包含截图、人物、参照物和怪物图片。复制时带上整个文件夹。旧方案可直接载入，保持原有边界；使用“编辑标定”另存时转换为三步方案，以保存截图中的人物位置作为目标，旧方案文件不改写，追加的怪物图片保留。

人物名字留空时使用标定图片；填写名字则启用本地 OCR，仅填写的名字与标定名字相同才使用原图片备用。参照物应始终可见，画面滚动时观察区域和回位位置跟随它；更换缩放比例或分辨率需要重新标定。怪物动作变化时，可点“追加怪物图片”补充特征。

定时 Buff 与其他模式共用一页：开关实时应用，槽位变更点“应用 Buff 设置”。“补一次”在运行且游戏处于前台时执行。守台先释放攻击并等待 150ms，再发送技能键；界面显示倒计时或等待条件。
