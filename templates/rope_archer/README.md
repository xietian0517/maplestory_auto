# 绳边射手模板

适用地图：**猴子沼泽3**（游戏内名称：猴子沼泽地3）；方案标识：`rope_archer`。
**野猪领地1** 对应的是 `random_jump` 方案。

当前版本 **v1.4.0**（内侧站位 / 光圈识别）。标题栏、启动日志和试识别日志均显示版本号；启动日志还显示实际程序路径。

按本次「猴子沼泽地3」参考截图裁出独立识别素材。不会读取旧名字模板或旧平台边界。

双击 `dist/MapleFarmArcher.exe`，或运行 `.venv/Scripts/python.exe rope_archer_gui.py`。
程序使用单独的 `rope_archer_config.json`。先点「试一下识别」，在 3 秒内切回游戏。
识别预览保存到程序目录下的 `captures/rope_archer_test.png`，不发按键；修正版同时保存无标注的 `captures/rope_archer_raw.png` 便于排查。
确认边界位于脚下平台内后，启动并切回游戏，F12 开始/暂停，F11 停止。

- 右侧指定平台范围内识别到猴子时持续按住 Shift，由游戏连续攻击。每帧复查，猴子消失时松开。按用户最新要求，不再限制两次点按。
- 被击退后持续按住方向键回位，截图期间保持按键；同方向只续持键时间，不重复发送按下/抬起事件。抵达后松开并停稳，不跳跃、不爬绳。
- 站位比上一版向平台内侧移 30px。偏离目标超过 20px 才回位，到目标左侧 6px 处松开，留出转向空间；目标附近的小幅变化不反复微调。进入右侧缓冲带时先向左回位，再考虑攻击或停稳等待。
- 启动/恢复需两帧确认；正常移动不因每帧位移较大而暂停。人物、平台未识别，人物高度不符或超出安全区时松键；恢复识别后重新判断。
- 独立线程每 5ms 检查暂停、失焦、退出状态与按键有效期。持键每帧续期，上限 400ms；方向键的期限只允许走到回位区以内，并预扣 4px 定位误差和 20ms 松键延迟。截图卡住也会到期松开，接近目标时可能提前松键再确认位置。已持有方向键时，回位和转向都会扣除截图识别期间的耗时。
- 截图识别超过 120ms 时丢弃该帧并松键。人物高度偏离标定超过 4px 或相邻帧高度变化超过 3px 时不移动、不攻击，等位置重新稳定；不在已标定平台范围时也停止。
- 该方案只使用独立 profile 的节奏和固定 Shift，不使用旧方案的跳跃、喝药、Buff 或随机节奏字段。

`profile.json` 的坐标全部相对 `anchor_foreground.png` 匹配中心，因此移动窗口、客户区去掉标题栏不影响坐标。
定位图块只保留平台前景，避开随镜头滚动变化的背景；平台阈值为 0.94。旧的 `anchor.png` 只作参考保留。
参考图中绳子 x=529；新版回位目标 x=463、起动容差 20px。主动右移上限 x=483，实际指令还预扣误差/延迟余量；已标定平台中心范围保持 x=285–511，仍在平台内但超过主动移动线时只向内回位。
蓝线是目标，橙线是主动右移上限，红线是已标定平台边界。边界为参考图估计，留出的距离只能降低主动走落风险，无法保证外力击退、速度超出估算或系统严重延迟时绝不掉落。
人物识别使用下方固定称号牌，因为完整名字会被宠物标签遮住。`player_native.png` 来自游戏原始画面，`player.png` 保留上传截图的像素版本；两者均保持 0.86 的阈值，并分别校正位置偏移。称号变化后需重新制作图片。

完整称号牌被猴子或宠物标签挡住时，自动改用局部识别：将称号牌拆成四段，至少两段各自达到 0.90，并推算出一致的完整称号牌中心（误差不超过 2px），才认定人物位置。片段的中心不直接作为人物位置，避免遮挡范围变化时坐标跳动。日志与试识别结果会显示「称号局部 2/4」或「称号局部 3/4」。完全遮住、仅剩一段、出现两个无法区分的位置时松键等待，不使用上次坐标继续走；高度和安全边界检查仍然生效。

`max_speed` 默认按 350px/s 保守估算移动上限，尚未在此角色实战校准。更高移动速度、改变缩放/分辨率、换地图、其他同称号角色、怪物动画或特效遮挡可能影响识别；应先检查预览。
`key_lease_secs` 是持键监护超时，并不是每次按键后必须松开的时长；识别正常时会持续续期。`scan_interval` 默认 40ms（不含截图识别耗时）。`move_min`、`move_max`、`attack_hold`、`attack_gap`、`burst_cooldown` 为旧版兼容字段，连续版不再使用。
`monkey_front.png`、`monkey_side.png`、`monkey_native_face.png` 和 `monkey_walk_face.png` 覆盖参考图与原始画面的姿势，同时匹配镜像；补充的脸部模板覆盖走动动作和掉落物遮挡。未见过的姿势可能漏检，此时等待而不盲攻。

头部/身体模板未命中时，用 `monkey_halo.png` 辅助识别：只比较浅黄色发光椭圆的颜色和轮廓，阈值 0.86；搜索限制在右侧平台头顶高度（相对平台锚点 y=270–318），不搜索地上的掉落物或下层。日志显示「头顶光圈」，预览标出 `MONKEY: halo`。此特征无需身体可见；本帧光圈及其他猴子特征都消失就松开 Shift，不用历史目标维持攻击。缩放、光圈暗淡或特效完全遮挡仍可能漏检。

运行中出现平台、人物、高度或边界识别异常时，先松键，再保存该类最新原图和诊断信息到 `captures/diagnostics/last_*_failure.png/json`。每类最多五秒更新一次，固定保留四类，方便复查，不无限累积截图。

模板随 exe 内置。需修改时，将本文件夹复制到 exe 旁的 `templates/rope_archer/`，同路径外部文件优先于内置模板。
